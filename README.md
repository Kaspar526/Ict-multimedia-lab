# 多媒體實驗室 · Media Quest

香港中四資訊及通訊科技科多媒體互動學習網站。

## 學習內容

- 圖片：點陣圖與向量圖的放大比較、應用與優缺點、色深與像素尺寸、長寬比的拉伸／留邊／裁切，以及依課本整理的圖片格式表。
- 文字：純文字與格式化文字同步預覽。
- 聲音：左右聲道、立體聲及單聲道試聽；取樣、量化及檔案大小。
- 影像：幀率同步比較及未壓縮／壓縮影像計算。

此版本已移除 DSE 題目分區。主題任務及 XP 只保留在使用者的瀏覽器，不會傳送學生紀錄。

## 執行

直接開啟 `index.html`，或使用靜態網站主機。網站不需要安裝套件或建置。

GitHub Pages 可設定從 `main` 分支的根目錄 `/` 發佈。

## 教材依據

解說根據提供的《多媒體元素及數碼化》第 4 章整理，模擬圖像由網站程式繪製。圖片格式表參考 p.4.8 表 4.3，以及 p.4.11–4.13 的向量圖內容。

原課本 PDF 及圖片並未包含在此儲存庫。
